# 高效交互平台

Windows 桌面端的手机协同工作台：**投屏 / 多开 / 文件互传**。
纯 Python 标准库（tkinter）实现，投屏引擎 scrcpy 与 adb 已随仓库携带，解压即用，不写注册表、不改系统环境，全程无需联网。解压后约 29 MB。

## 功能

### 投屏

选分辨率（720 / 1080 / 1920 / 2688）、帧率（30 / 60），勾选「手机熄屏省电」后启动，手机会熄屏但电脑照常显示。

快捷键（默认修饰键 = 左 Alt，可在 `scrcpy/config.ini` 改成 `lctrl`）：

| 组合 | 作用 | 组合 | 作用 |
|---|---|---|---|
| Alt + P | 电源 / 锁屏 | Alt + F | 全屏 |
| Alt + H | 主页 | Alt + V | 粘贴电脑剪贴板 |
| Alt + B | 返回 | Alt + ↑ / ↓ | 音量加 / 减 |
| Alt + S | 多任务 | Alt + N | 通知栏 |
| Alt + O | 熄屏 / 亮屏 | | |

### 多开

「加载应用列表」→ 搜索或直接找 → Ctrl / Shift 多选 → 「打开选中应用」。每个应用开一个独立虚拟屏窗口，点哪个控制哪个。建议不超过 3 个，每个副屏都会占用手机的 GPU 合成与视频编码。

### 文件

左栏是电脑（默认桌面），右栏是手机（默认 `/sdcard/Download`）。

- 图片显示真实缩略图，非图片按类型显示彩色块；只为可见格子取图，几千张的相册也不会卡。
- 从桌面直接把文件拖进右栏即可入手机；拖到某个文件夹格子上就放进那个文件夹。
- **中文文件名不会被截断**：先用 ASCII 临时名上传 → 手机端按 base64 改回真名 → 回读字节数校验，拉取同理。
- 两栏都带搜索（空格分词 = 同时满足）、类型 / 排序筛选、含子目录、图 / 列视图切换。
- 底部另有「看手机屏幕 / 截取手机画面 / 录制视频（调用手机控制中心录屏）/ 打开接收文件夹 / 刷新两边」。

## 快速开始

1. 安装 **Python 3.11+**（安装时勾选 *Add python.exe to PATH*），确保带 tkinter。
2. 手机上开启「开发者选项」与「USB 调试」，插上数据线，在手机弹窗里点**允许**；通知栏的 USB 模式选「传输文件」。
3. 双击 **`启动.bat`**（不要直接双击 `.py`，避免把源码当文本打开）。

没有 `启动.bat` 时可命令行运行：

```bash
python "高效交互平台.py"
```

想确认环境是否正常，双击 `工具\自检.bat`：会检查默认目录、位置栏、桌面拖放，并真的往手机推一个中文名文件再拉回来比对字节数，最后自动清理。

## 常见问题

**设备显示未连接？** 检查数据线是否支持数据传输、USB 调试是否授权、USB 模式是否为「传输文件」。换一根确定能传数据的线往往就解决了。

**换了一台手机就「未检测到设备」？** 先看左下角那行小字，程序会把原因直接写出来，不用自己猜：

| 左下角显示 | 卡在哪一层 | 怎么办 |
|---|---|---|
| 电脑没看到调试接口 · 换线试试 | 线材 / USB 调试开关 / 仅充电模式 | 换一根能传数据的线；确认 USB 调试已开；USB 用途选「传输文件」 |
| 接口复位失败 · 换线或换口 | 电气层（问题码 43） | 改注册表无用：换短线、直插机身 USB 口，不要过扩展坞 |
| 接口未注册 · 点「修复 USB 接口」 | 驱动注册层 | 点按钮，允许管理员权限，跑完点「重新检测」 |
| 接口驱动异常 · 点「修复 USB 接口」 | 驱动加载失败（问题码 10/28/31） | 同上，脚本会自动处理冲突的注册表值 |
| 接口正常 · 等手机确认授权 | 手机端授权 | 在手机屏幕上点「允许 USB 调试」并勾选「始终允许」 |

**为什么会这样**：Android 的 ADB 接口在 USB 描述符里用 `Class_FF & SubClass_42 & Prot_01` 标识。Windows 装上通用 `winusb.inf` 后，只有设备自己上报了设备接口 GUID，`winusb.sys` 才会把这个接口注册进系统；没上报，设备管理器看着一切正常，但 adb 扫描不到任何东西。

同一个接口上，`DeviceInterfaceGUID`（单值）与 `DeviceInterfaceGUIDs`（多值）**不能同时存在**——两个都有会让 `winusb.sys` 直接起不来，设备管理器里显示问题码 31。这是本程序踩过的真实坑，修复工具会优先删掉后加的多值、保留设备原有的单值。

本程序的诊断与修复都按这个协议特征识别接口，**不认厂商 ID**，换任何 Android 机型都适用。

**修复工具**：`工具\USB诊断修复.bat`（双击会请求管理员权限，也可以从程序左下角的「修复 USB 接口」按钮启动）。它会：

1. 按兼容 ID 找出所有 ADB 接口，打印状态、问题码与已有的注册表值
2. 问题码 31/10/28 → 判断是单值/多值冲突还是真的缺配置，删掉冲突的多值、保留设备原有单值，重启接口
3. 状态正常但未注册 GUID → 写入 `{dee824ef-…}`（WinUSB）与 `{f72fe0d4-…}`（ADB）；若已有单值则不再写多值，避免造出冲突
4. 问题码 43 → 不碰注册表，直接提示换线换口
5. **自动跑两轮**：清完残留的设备重新枚举出来是「问题码 0 但未注册 GUID」，一轮修不彻底，第二轮接着补，一次点击走完
6. 日志写到 `usb-diag.log`，非管理员时会如实报「需要管理员权限」而不是假成功

修复完成后设备常先显示为 `unauthorized`，这是**修好的标志**（adb 已经能看到它了）——在手机屏幕上点「允许 USB 调试」并勾选「始终允许」，随即变成 `device`。弹框没出现就拔线重插一次再跑。

**文件进了手机但文件管理器找不到？** 确认右栏路径是 `/sdcard/Download`。不要停在 `/sdcard/我的文件`——那是系统私有目录，Android 11 起对 adb 不可见。

**文件名变短 / 丢扩展名？** 那是旧版直接 `adb push` 中文名的结果；本版改为「ASCII 临时名 + 手机端改名 + 回读校验」，正常不会复现。

**不要把文件拖到投屏窗口上。** scrcpy 自己收拖放会直接调 `adb push`，中文名一样会被截断；要传中文名文件请拖进「文件」页右栏。
